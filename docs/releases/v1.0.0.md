# v1.0.0 — 小米10青春版 (vangogh) MIUI 13 · KernelSU 内核

第一个**实机跑过**的构建。非 GKI 的 4.19 内核也能上 KernelSU，做法是把小米的 vendor 驱动
编进内核，绕开 vendor 模块的 ABI/CRC 限制，而不是加载官方 `.ko`。

```
设备    M2002J9E / vangogh / SM7250 (lito)
系统    MIUI 13  V13.0.7.0.SJVCNXM  (Android 12)
内核    Linux 4.19.157
        Driftwood 3f1ef13 + MIUI 私有驱动 (MIHW/MIGT/MILLET/SF_BINDER/PERF_CRITICAL_RT_TASK)
        CONFIG_QCA_CLD_WLAN=y（Wi-Fi 驱动内置）
root    KernelSU v0.9.5（非 GKI 最后支持版本，kprobe 模式）
```

## 实测状态

| 功能 | 结果 |
|---|---|
| 开机进入 MIUI 13 | ✅ |
| Wi-Fi | ✅ 5GHz 866 Mbps，正常获取 IP |
| KernelSU root | ✅ Termux 授权后 `su` 可用 |
| Magisk 模块迁移 | ✅ 自动识别并迁移 |
| **音频** | ❌ **完全无声**（通话音、媒体音都没有） |
| 相机 / 指纹 / 蓝牙 / 传感器 | ⚠️ 未逐一回归（指纹标定数据在 persist，未受影响） |

音频是这个版本唯一的大缺口：`techpack/audio` 内置会因 q6/adsp 早于 ADSP 固件探测而 panic，
外置成 `.ko` 又卡在重复符号。所以本版**不带音频**，回滚或等下个版本。

## 安装

```bash
# 0) 前提：解锁 BL；并且已经备份过 boot / dtbo / persist / modemst1/2 / fsg
xz -dk boot-vangogh-ksu-0.9.5.img.xz            # 得到 128 MiB 的 boot 镜像
sha256sum boot-vangogh-ksu-0.9.5.img            # 对比 SHA256SUMS.txt 中解压后的那一行

fastboot boot boot-vangogh-ksu-0.9.5.img        # ① 先临时启动，不写分区，重启即恢复
# 确认能进系统、Wi-Fi 正常、KernelSU 管理器显示「已安装」之后：
fastboot flash boot boot-vangogh-ksu-0.9.5.img  # ② 持久化
```

管理器**必须**用本页的 `KernelSU_v0.9.5.apk`。设备上若已装有更高版本，先
`adb uninstall me.weishu.kernelsu`，否则会 `INSTALL_FAILED_VERSION_DOWNGRADE`；
新版管理器只认 GKI 内核，装上会显示「未安装」。

## 校验

```bash
sha256sum -c SHA256SUMS.txt     # 压缩包摘要；解压后镜像的摘要也在同一文件末尾
```

## 注意

- **只适用于 vangogh + MIUI 13 `V13.0.7.0.SJVCNXM`**。boot header v2 里的 dtb 是从该版本
  原厂镜像复用的，系统版本不同可能导致无法启动。
- 本 Release 不含任何本机身份数据（`persist` / `modemst1/2` / `fsg` 都没有上传）。
- 刷机风险自负；务必先 `fastboot boot` 验证，再 `flash`。
